# 💬 NeatChat++

A real-time chat application built using Node.js and Socket.io, with a focus on efficient message handling and scalable design using core data structures.

---

## 🚀 Features

* 🔹 Real-time messaging between users
* 🔹 Chat history storage
* 🔹 Basic user authentication (login/signup)
* 🔹 Message search functionality
* 🔹 Spam / offensive message filtering (basic)
* 🔹 Optimized recent chats using LRU Cache

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express
* **Real-time:** Socket.io
* **Data Handling:** Custom Data Structures (Trie, LRU Cache, Heap)

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/NeatChat.git
```

2. Navigate to project folder:

```
cd NeatChat
```

3. Install dependencies:

```
npm install
```

4. Run the server:

```
node src/server.js
```

5. Open browser:

```
http://localhost:3000
```
